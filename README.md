# local_syllabus — Силабус курсу для Moodle

Плагін Moodle для створення силабусу освітньої компоненти прямо в курсі. Силабус можна **заповнити вручну** або **згенерувати автоматично з контенту курсу**, а тоді доопрацювати. Макет документа, розділи та формат даних повторюють «Конструктор силабусів ХДУ», тож JSON-файли переносяться між конструктором і Moodle в обидва боки.

## Можливості

- **Сторінка «Силабус» у курсі** (меню курсу → *Більше* → *Силабус*). Студенти бачать її лише після публікації.
- **Генерація з контенту курсу**:
  | Звідки береться в курсі | Що заповнюється в силабусі |
  |---|---|
  | Повна назва, опис, дата початку курсу | Назва, анотація, навчальний рік |
  | Категорія та батьківська категорія | Кафедра, факультет |
  | Викладачі з правом редагування | ПІБ, e-mail, телефон викладача |
  | Розділи курсу (включно з підрозділами Moodle 4.5+) | Схема курсу: теми, поділені на N модулів, з годинами лекцій і практичних |
  | Активності в розділах | Зміст теми (матеріали та завдання) |
  | Оцінювані активності (журнал оцінок) | 10.1 / 10.2 Поточний контроль модулів із балами, 10.3 Підсумковий контроль, форма контролю (екзамен/залік) |
  | Терміни здачі завдань і тестів | Політика курсу → дедлайни |
  | Файли, книги, теки / гіперпосилання | Основна література / Інтернет-ресурси (наскрізна нумерація) |
  | Компетентності курсу (idnumber `ЗК…`, `ФК…`, `ПРН…`) | Компетентності та програмні результати навчання |
  | Умови завершення «інші курси» | Передумови вивчення курсу |
  | BigBlueButton, Zoom тощо | Технічне забезпечення, сервіс для конференцій |
  | Власні поля курсу з назвами `credits`, `specialty`, `educational_program`, `field_of_study`, `education_level`, `semester`… | Однойменні поля силабусу |
- **Режими злиття**: заповнити лише порожні поля (ваші правки лишаються) або перезаписати все.
- **Генерація з ШІ (необов’язково, Moodle 4.5+)**: через вбудовану підсистему ШІ Moodle (дія «Генерувати текст») пише анотацію, мету, завдання та зміст тем. Години, бали та література завжди беруться з курсу, а не від ШІ. Перед першим використанням потрібно прийняти політику використання ШІ.
- **Редактор** з усіма розділами конструктора (01–12), зокрема зі схемою курсу (модулі та теми), завантаженням підпису завідувача кафедри та перевіркою збігу годин.
- **Експорт**: PDF (TCPDF, шрифт FreeSerif з кирилицею, макет ХДУ) та JSON у форматі конструктора (`{metadata, syllabus}`).
- **Імпорт** JSON-файлу з конструктора силабусів.
- Мовні пакети: українська та англійська. Події (переглянуто / оновлено), Privacy API.

## Встановлення

1. Скопіюйте вміст репозиторію в `<moodle>/local/syllabus`.
2. Відкрийте *Адміністрування сайту → Сповіщення* і завершіть встановлення.
3. Налаштування: *Адміністрування сайту → Плагіни → Локальні плагіни → Силабус курсу*:
   міністерство/університет/місто для титульної сторінки, кредити за замовчуванням, годин у кредиті,
   шаблони політики курсу, технічного забезпечення та критеріїв підсумкового контролю, увімкнення ШІ.

Потрібен Moodle 4.1 або новіший; генерація з ШІ працює з Moodle 4.5+ за наявності налаштованого постачальника ШІ.

## Права доступу

| Право | За замовчуванням |
|---|---|
| `local/syllabus:view` | студент, асистент, викладач, менеджер |
| `local/syllabus:edit` | викладач, менеджер |
| `local/syllabus:generate` | викладач, менеджер |

## Як працювати

1. У курсі відкрийте **Силабус → Згенерувати з контенту курсу**, оберіть кількість змістових модулів (і за бажанням «Покращити тексти за допомогою ШІ»).
2. Перевірте й доповніть поля в редакторі (освітня програма, спеціальність, протокол, підпис тощо). Увімкніть **Опубліковано**.
3. Завантажте PDF або збережіть JSON, щоб продовжити роботу в конструкторі.
